# 🎮 Fortnite de Cria

Projeto simples desenvolvido para praticar conceitos de desenvolvimento e DevOps.

## 🚀 Tecnologias

- Python
- Flask
- Docker
- Git

## 📦 Como executar

Clone o projeto e execute:

docker build -t fortnite-de-cria .
docker run -p 8080:8080 fortnite-de-cria

A aplicação estará disponível em:

http://localhost:8080
